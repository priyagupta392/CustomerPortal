# Customer Portal Automation

## Project Overview
Automation framework developed using Selenium WebDriver,
Java, TestNG and Maven.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Extent Reports

## Test Modules
- Login
- Discovery
- Profile
- Cart
- Holdings
- Portfolio

## Framework Structure

src
 ├── main
 │   ├── java
 │   └── resources
 └── test
     └── java

## Reporting
Extent Reports are generated after test execution.

## How to Run
1. Clone the repository
2. Import as Maven project
3. Update configuration
4. Run testng.xml
